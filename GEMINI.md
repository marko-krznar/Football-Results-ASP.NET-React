# Project Mandates (GEMINI.md)

This file contains project-specific instructions and standards that take precedence over general defaults.

## Project Structure
- **Frontend:** Located in the `frontend/` directory.
- **Backend:** Located in the `backend/` directory (currently empty).

## Development Standards
- **Styling:** Use MUI components and Sass for custom styling.
- **Components:** Functional components with TypeScript interfaces for props.
- **Data:** Use the mock data in `frontend/src/data/` for now.

## Deployment (Render Static Site)
Refer to `frontend/README.md` for detailed deployment instructions.
- **Root Directory:** `frontend`
- **Build Command:** `npm install && npm run build`
- **Publish Directory:** `dist`
